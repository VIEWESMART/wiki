# HDMI 接口显示屏

**即插即用，可视化呈现。**

优奕视界 HDMI 显示屏系列采用原生 HDMI 接口，支持**免驱**即插即用。
完美兼容**树莓派**、**Jetson Nano**、**Windows PC**、**Android** 以及各类 Linux 工业电脑。

<div class="grid cards" markdown>

-   :material-power-plug: **免驱 (Driver Free)**
    ---
    无需驱动。视频通过 HDMI 传输，供电与触摸信号通过 USB (HID Protocol) 传输。

-   :material-raspberry-pi: **树莓派适配 (RPi Ready)**
    ---
    针对树莓派生态优化。部分型号带安装孔，可无缝集成。

-   :material-monitor-dashboard: **异形屏 (Unique Shapes)**
    ---
    除标准屏外，我们还提供**条形屏 (Bar Type)**与**圆形/方形 (Round/Square)**显示屏，满足个性化 UI 设计。

</div>
