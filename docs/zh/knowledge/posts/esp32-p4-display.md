# ESP32-P4 在多媒体与 HMI 显示应用中的使用

!!! abstract "快速结论"
    本指南解释了ESP32-P4显示应用程序，相关的设计权衡以及工程师在选择显示解决方案时应验证的点。

- 系统了解ESP32-P4 在多媒体与 HMI 显示应用中的使用，包括关键原理、优缺点、应用场景和工程选型要点。
- 根据下文比较相关技术、应用条件和设计取舍。
- 最终选型前，应确认光学、电气、结构、环境与量产要求。

其他信息：

ESP32-P4是一个高性能微控制器 (MCU)，配备32位RISC-V双核处理器。它具有强大的音频和视频处理功能，丰富的边缘接口以及低功耗特性，使其特别适合物联网 (IoT) 设备和各种智能应用。下面详细介绍ESP32-P4的规格，功能和核心能力，重点是其音频和视频多媒体功能以及人机互动功能。

## I.概述

ESP32-P4是一个专门为物联网 (IoT) 设备设计的高性能微控制器 (MCU).它由32位RISC-V双核处理器构成，时钟频率达400MHz，提供强大的图像和语音处理功能。该芯片集成了高性能 (HP) 系统和低功耗 (LP) 体系。HP系统由双核处理器驱动，而LP系统是由单核处理ctor驱动的，使其适合低功率应用。 ESP32-P4还集成了丰富的外围接口，包括多个GPIO，各种通信接口和传感器接口。

## II.核心规格

- 处理器：

- **高性能处理器**:32位RISC-V双核处理器，时钟频率达400MHz.

- **低功耗处理器**:32位RISC-V单核处理器，时钟频率高达40MHz.

- 记忆：

- **在芯片上存储**:

- 128 KB HP ROM

- 768 KB HP L2MEM

- 16 KB LP ROM

- 32 KB LP SRAM

- 8 KB 系统密切连接的内存 (TCM)

- **外部存储**:

- 支持16MB或32MB的PSRAM用于扩展内存。

- 支持存储程序和数据的最大128MB外部闪存。

- **包装**:

- 适合小型设计的QFN104 (10×10mm) 包装。

## III. 音频和视频多媒体能力

ESP32-P4在音频和视频处理方面卓越，具有以下核心功能：

### 1.图像处理

- **JPEG编码器**:

- 支持8位彩色样本和原始图像格式，如RGB888,RGB565,YUV422和GRAY.

- 支持YUV444,YUV422,YUV420等压缩图像格式。

- 静态图像编码可以达到4K分辨率，MJPEG编码的最高性能为720p@88fps或1080p@34fps.

- 静态图像解码可以达到4K分辨率，MJPEG解码的最大性能为720p@88fps或1080p@30fps.

- **图像信号处理器 (ISP)**:

- 最高分辨率为 1920 x 1080.

- 三个输入道：MIPI CSI,DVP和DW-GDMA.

- 输入格式支持RAW8,RAW10和RAW12.

- 输出格式支持RAW8,RGB888, RGB565,YUV422，和YUV420.

- 支持Bayer域噪音降低 (BF)，消化 (Demosaic)，颜色校正矩阵 (CCM)，马校正，磨损 (Edge) 和对比度/光线/和亮度调整等功能。

- ** 像素处理加速器 (PPA)**:

- 支持图像旋转，扩展和反射。

- 支持ARGB8888,RGB888,R GB565和YUV420等格式。

- 支持水平和垂直扩展，为扩展因子提供8位整数部分和4位分量部分。

- 支持水平和垂直镜像。

- **相机-LCD控制器**:

- 支持8/16/24位平行输出模式和RGB,MOTO6800和I8080等多个LCD模式。

- 支持8/16位平行输入模式和DVP图像传感器。

- 支持同时连接LCD和相机设备。

- **H264编码器**:

- 支持YUV420渐进视频，最高编码性能为1080p@30fps.

- 支持I-框架和P-框架，以及GOP模式和双流模式。

- 支持4 x 4 和16 x 16 内光块分区。

- 支持所有间预测宏区分模式：4 x 4, 4 x 8, 8 x 4, 8 x 8,8 x 16, 16 x 8 和 16 x 16.

- 支持1/2和1/4像素精确的运动估计。

- 支持适应环境变量长度编码 (CAVLC).

- 支持P跳块，而P切片支持I宏块。

- 支持对光线和染色元件的量化结果降低。

- 支持固定QP和宏区块级位率控制。

- 支持MV合并功能，可将每个宏块的MV输出到内存中。

- 支持兴趣区域 (ROI)，可在任意位置配置高达8个矩形 ROI地区。

- **MIPI摄像头连续接口 (CSI) **:

- 符合MIPI CSI-2协议，使用DPHY v1.1.

- 两行 x 1.5 Gbps，支持RGB888,RGB666,RGB565,YUV422,YUV420,RAW8,RAW10和RAW12的输入格式。

- **MIPI显示连续接口 (DSI)**:

- 符合MIPI DSI协议，使用DPHY v1.1.

- 2行 x 1.5 Gbps，支持RGB888,RGB666,RGB565和YUV422的输入格式。

- 输出格式支持RGB888,RGB666和RGB565.

- 使用视频模式输出视频流，并支持输出固定图像模式。

### 2. 音频处理

- **I2S控制器**:

- 三个标准的I2S接口支持主和从设备模式，以及全双或半双模式。

- 支持I2S连续8位，16位，24位和32位数据传输和接收模式。

- 支持10 kHz至40 MHz之间的频率的BCK钟。

- 支持TDM PCM,TDM MSB调整，T DM标准和PDM接口。

- I2S0支持PDM到PCM输入和PCM到PDM输出。

- **LP I2S控制器**:

- 仅支持从设备模式和I2S连续16位数据接收模式。

- 支持从10 kHz到5 MHz之间的频率的BCK钟。

- 支持TDM PCM,TDM MSB调整，T DM标准和PDM RX接口。

- 音频 PLL钟

- 提供高度可配置，低度和精确的时钟源，支持在6 - 125MHz范围内调节频率。

## IV. 人机互动能力

ESP32-P4支持多种人机互动方法，包括显示屏，摄像头和语音识别，使其适用于智能家居，工业自动化和医疗保健等各种应用场景。

### 1. 显示能力

- **LCD接口**:

- 支持24位液晶接口，适合各种显示器。

- 支持多种LCD模式，包括RGB,MOTO6800和I8080.

- 支持8/16/24位平行输出模式，适用于不同分辨率的显示器。

- 没有什么可做。

- 支持MIPI DSI接口，适合高速数据传输。

- 支持2道×1.5Gbps，适合高分辨率显示器。

- 支持RGB888,RGB666和RGB565等输出格式。

### 2. 摄像头能力

- 在此之前，

- 支持MIPI CSI接口，适合高速数据传输。

- 支持2道×1.5Gbps，适合高分辨率摄像头。

- 支持RGB888,RGB666,RGB565,YUV422,YUV420,RAW8,RAW10和RAW12等输入格式。

- **DVP接口**:

- 支持DVP图像传感器，适用于各种整理的摄像头。

- 支持8/16位平行输入模式，适用于不同分辨率的相机。

### 3. 语音识别能力

- **I2S接口**:

- 支持多个I2S接口，适用于音频输入和输出。

- 支持各种音频格式和采样率，适合语音识别和音频处理。

- 音频 PLL钟

- 提供低和精确的时钟源，确保高质量的音频信号传输。

- **麦克风接口**:

- 支持外部麦克风连接，适用于语音识别和录音。

## V.周边接口

ESP32-P4集成了丰富的边缘接口，支持多个通信协议和传感器接口。

### 1. 通信接口

- 排放时间：

- 五个UART接口支持异步通信 (RS232和RS485) 和IRDA.

- 支持硬件流量控制和软件流量的控制，通信速度高达5 Mbps.

- 标签：

- 多个SPI接口支持主和从设备模式。

- 支持各种SPI模式，包括1-位SPI,2-位双SPI,4-位四分快三，QPI,8-位OctalSPI和OPI.

- 支持各种时钟频率和数据长度配置。

- **I2C**:

- 两个I2C公交接口支持主和从设备模式。

- 支持标准模式 (100 Kbit/s)，快速模式 (400 Kbit / s) 和高速模式 (800 K Bit / s).

- **I3C**:

- 一个I3C主机接口和一个I3c从设备接口。

- 支持SDR模式，动态地址分配和In-Band中断。

- 连接器：

- 高速USB 2.0 OTG支持高速和全速的速度。

- 全速USB 2.0 OTG支持全速和低速率。

- 支持CDC-ACM虚拟序列端口和JTAG适配器功能。

- **Ethernet MAC**:

- 支持通过MII或RMI接口传输数据。

- 支持IEEE1588-2002和IEEEE1588-2008

- 支持节能以太网 (EEE) 和魔法包检测。

- **TWAI®**:

- 支持ISO 11898-1协议，适用于汽车和工业通信。

- 支持标准的框架格式 (11-位ID) 和扩展的框格式 (29-位ID).

- 支持多种操作模式，包括正常模式，只听模式和自我测试模式。

- **SD/MMC 主机控制器**:

- 支持SD卡版本3.0和3.01,SDIO版本3.0,CE-ATA版本1.1.

- 支持高达80MHz的时钟输出和1位，4位和8位数据总线模式。

### 传感器接口

- 触摸传感器：

- 支持最多14个感应容量GPIO，适合触摸屏和接近感测。

- 支持防水，频率跳跃检测和数字过功能。

- **温度传感器**:

- 内置温度传感器，测量范围为 -40 °C至125 °C.

- 适用于监测芯片内部温度。

- **模拟到数字转换器 (ADC):**

- 两个12位SARADC支持14个频道的测量。

- 适用于收集和处理各种模拟信号。

- **模拟电压比较器**:

- 两个整理的模拟电压比较器组，每个组包含2个PAD.

- 适用于比较两个PAD之间的电压关系或与内部稳定电压。

## VI. 安全特征

ESP32-P4集成多个安全功能，以确保数据和操作的安全。

- **安全启动**:

- 支持安全启动机制，以确保固件的完整性和真实性。

- **eFuse 输出口号**:

- 为存储密钥或设备ID提供一次性可编程的安全性。

- **加密硬件加速器**:

- 支持AES-128/256加密算法，符合FIPS PUB 197标准。

- 支持符合FIPS PUB 180-4标准的SHA加速器。

- 支持非对称加密的RSA加速器。

- 支持圆曲线加密的ECC加速器。

- 支持ECDSA圆曲线数字签名。

- 支持数字签名和HMAC.

- 关键经理：

- 使用物理不可克隆函数 (PUF) 生成硬件独一键 (HUK).

- 支持键存储和动态键切换。

- **访问权限管理**:

- 支持DMA和APB访问权限管理。

- 支持异常信息记录。

## VII. 电力管理

ESP32-P4采用先进的功率管理技术，支持多种功耗模式，使其适用于低功耗应用。

- **电力消耗模式**:

- **激活模式**:CPU正在运行，所有外围设备都可以工作。

- **轻睡眠模式**:CPU暂停运行，一些外围设备可以关闭以减少电力消耗。

- **深度睡眠模式**:CPU和大多数外围设备被关闭，而低功耗内存和一些外围装置仍然运行。

- **电源管理单元**:

- 支持多个电源域，包括HP电源领域，LP电源区域和模拟电源区。

- 支持多个电源管理功能，如低压监测和电源切换。

## VIII. 应用情况

ESP32-P4适用于各种应用场景，包括但不限于：

- **智能家居**：智能家庭电器控制，智能照明，智能的安全等

- **工业自动化**：工业设备控制，传感器数据采集，远程监测等

- **医疗保健**：医疗器械监测，患者数据采集，远程医学等

- **消费电子**：智能扬声器，智能摄像头，智能的手表等

- **智能农业**：环境监督，作物增长监测，智能灌等

- **POS机器**：支付终端，数据采集和传输。

- **服务机器人**：导航，避免障碍，人类与机器互动等

- **音频设备**：音乐播放器，语音助手，音频处理等

- **一般低功耗物联网传感器中心**：从多个传感器获取和传输数据。

- **一般低功耗物联网数据记录器**：数据录制和传输。

## 九。结论

ESP32-P4是一个高性能，低功率的微控制器，具有强大的音频和视频处理能力，丰富的外围接口集以及多种支持人机互动的能力。它适用于各种应用场景，特别是需要音频和视频处理以及低功耗设计的物联网设备。通过其高性能处理器，丰富的外围接口和先进的功率管理技术，ESP32-P4可以满足各种复杂应用程序的要求，为开发人员提供灵活，有效和可靠的平台。
