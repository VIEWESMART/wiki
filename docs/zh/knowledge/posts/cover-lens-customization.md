# 显示产品盖板定制指南

!!! abstract "快速结论"
    盖板玻璃（Cover Lens）是用户看到与触碰的第一层。它既要"能透光"，也要"能遮挡人眼可见区、能开孔藏接口、能印 Logo、能叠耐磨与抗菌镀膜，还能配合 2.5D / 3D 异形与光学贴合"。本文按"选材 / 切割 / 印刷 / 玻璃替代 / 抗菌 / 彩色 / 超大 / 异形 / 光学贴合"九大定制维度逐一展开，给出每个能力的工程含义、典型图样与设计边界。

## 核心要点

- 盖板的核心材料是钢化玻璃，**轻量替代品**是 PMMA（亚克力）与 PC（聚碳酸酯）。
- **定制形状**是盖板定制的基础：摄像头孔、传感器孔、机械表盘孔、按键孔、触摸扩展区都能用 CNC / 水刀 / 激光切出来。
- **印刷方式**决定信息层体验：可见 Logo、隐藏图标（点亮时显示）、功能图标，配 LED 透光可实现动态状态指示。
- **彩色玻璃**（全黑 / 全白）能在熄屏状态下让设备呈现"全黑一体"，是高端家电与智能家居流行的方案。
- **2.5D / 3D 异形 + 光学贴合**是工业设计差异化重点，适用于摩托仪表 / 海洋 / 智能家居。

## 1. 盖板与定制总览

盖板是用户界面最直接可见的部分，必须能长时间保持外观，抵抗雨水、海水、阳光直射、清洁化学品、工业油、厨房油脂、家庭粉尘等使用环境。

作为显示产品定制专家，优奕视界 长期跟踪最新的设计趋势与制造工艺，并与材料供应商共同探索新材料 / 新工艺 / 新形状的可能性。

## 4. 玻璃替代品

高透光 **PMMA（聚甲基丙烯酸甲酯，亚克力）** 和高透光 **PC（聚碳酸酯）** 是常见的玻璃替代材料，视觉上接近玻璃，但更轻、更耐冲击。

- **强韧性**：耐冲击，不会破碎。
- **透光性**：接近玻璃。

适合用于：医疗器械、便携产品、可穿戴、家电触摸区。当需要更强的耐冲击能力（儿童使用场景、移动场景）时优先考虑 PMMA / PC；反之优先玻璃（耐刮、清晰度）。

## 8. 2.5D / 3D 异形盖板

异形盖板能从单一平面延伸到曲面甚至三维立体形状，与产品造型深度融合。

<figure markdown="span" class="displaywiki-figure">
  [![可由玻璃 / PC / PMMA 实现](cover-lens-customization-they-can-be-achieved-using-glass-polycarbonate-or-acrylic-pmma.png){ width="760" loading="lazy" }](cover-lens-customization-they-can-be-achieved-using-glass-polycarbonate-or-acrylic-pmma.png){ .displaywiki-image-link title="查看原图" }
  <figcaption>图 8-1 异形盖板可由玻璃 / PC / PMMA 实现</figcaption>
</figure>

显示器与盖板之间填满光学树脂以贴合（详见 [空气贴合与光学贴合对比](air-vs-optical-bonding.md)）。

常见应用：智能家居控制面板、海洋船舶控制、摩托车仪表盘、车规显示。
!!! warning "量产注意"
    在量产或恶劣工况（高低温、湿热、振动、ESD）下，注意该参数的 datasheet 曲线，超出范围会显著降低寿命。


特点：

- 不同尺寸的盖板玻璃可定制。
- 可配合触摸功能。
- 可选用玻璃或塑料基材。

## 9. 光学贴合

随着户外或高亮场景设备增多，**显示清晰度与视角**成为设计关键。光学贴合是在显示器与盖板之间填满光学树脂，用以消除空气层、改善强光下的可读性。

## 10. FAQ

??? question "Q1：盖板应该选玻璃、PMMA 还是 PC？"
    玻璃：耐刮、透光率最高、热稳定性好、易做 AG / AR / AF 镀膜；**消费类、工业、医疗、汽车首选**。PMMA：透光率稍低但接近玻璃、重量轻、**不易碎但相对易划伤**，适合家电、桌面设备、智能家居。PC：耐冲击最强、透光率略低、**抗冲击场景**如儿童使用、可穿戴优先。

??? question "Q2：如何让设备熄屏时与机身融为一体？"
    方案是**全黑印刷（黑胶 / 黑色油墨）**：在盖板背面（贴显示那面）的非视区印不透光黑油墨，遮住视区外的机械结构与镀膜反射。**要点是印刷的边界要与 LCD 视区精准对齐**，否则会有溢光。优奕视界 工厂对位精度 ± 0.2 mm。

??? question "Q3：隐藏图标是怎么做出来的？"
    隐藏图标的原理是**半透油墨 + LED 背光**：在玻璃背面按预期图标形状印半透油墨，未亮灯时几乎看不到；点亮 LED 后油墨透出图形。这套方案能做出"用常干净，用时浮现"的 UI 体验。

??? question "Q4：盖板玻璃厚度怎么选？"
    消费电子主流 0.5–0.7 mm；车载、工业可视场景 1.1–1.8 mm；超大尺寸或 3D 异形 2.0–3.0 mm。**厚度越大刚性越好、但越重、越影响透光与触控灵敏度**。

??? question "Q5：抗菌镀膜对触摸有影响吗？"
    正规的"表面型"或"玻璃内部型"抗菌镀膜都不影响 PCAP 触控；**银离子型抗菌膜需要看透明性**，金属氧化物纳米型（TiO₂、ZnO）更适配高透明场景。

??? question "Q6：2.5D 与 3D 盖板的取舍是什么？"
    2.5D：边缘倒圆，配合平面 LCD，工艺成熟、成本可控、贴合难度一般。3D：曲面盖板，多与曲面 / 异形显示器搭配，**光学贴合难度大**，常需先用模具热弯再做边缘研磨，**不可量产**的小批量项目首选 3D，**大批量**优选 2.5D。
