# 显示屏定制、MOQ、交期与订购常见问题

!!! abstract "快速结论"
    定制显示屏的常见门槛可以概括为三组数字：打样约 7–25 个工作日，定制项目 MOQ 通常在 500–3000 件，量产出货约 30–40 个工作日。标准品 MOQ 为 1 件，500 件以下的定制订单通常需要承担一次性设置费用。可定制的范围覆盖触摸屏外形与尺寸、FPC 走向、丝印标志与接口位置。长期供应方面，即使关键驱动 IC 停产，也会通过兼容 IC 替代或重开模具维持连续供货。

## 核心要点

- 可定制内容：触摸屏形状与尺寸、FPC、丝印标志、接口位置等，标准品之外的部分都可谈。
- 打样周期约 7–25 个工作日，量产交期约 30–40 个工作日，均为参考值，随项目复杂度浮动。
- 标准品 MOQ 为 1 件；定制项目 MOQ 多在 500–3000 件，可按年需求分批交付。
- 500 件以下的订单通常含一次性设置费用，因此单价高于标准版本；付款方式按订单规模区分。

## 1. 显示屏定制能做到什么程度

可以定制的内容包括触摸屏的形状与尺寸、FPC（柔性电路板）的走向与长度、丝印标志（Logo）以及接口位置等。这些改动让显示屏能够适配既有的整机结构与外观要求，而不必反过来修改结构件。

**打样周期**：样品生产通常需要 7 至 25 个工作日。该时间仅供参考，具体项目会因定制程度、物料齐套情况与工厂排期而有所不同。

## 2. MOQ 与批量交付

| 类型 | MOQ | 说明 |
|---|---|---|
| 标准品 | 1 件 | 无需定制，直接选型采购 |
| 定制项目 | 通常 500 – 3000 件 | 依具体定制要求而定，可协商 |
| 小批量试产 | 可支持 | 用于验证设计与市场反馈 |

如果项目的年需求量超过 3000 件，可以拆分为多个批次交付，从而降低单次备货的资金与库存压力。

## 3. 成本构成与交期

**成本**：取决于订购数量。对于 500 件以下的订单，通常会产生一定的初始设置费用（如开模、治具与首件确认），这使得单件成本高于标准版本。

**交期**：在完成样品测试确认并提交批量订单后即安排生产，交付时间通常在 30 至 40 个工作日之间。该时间同样仅供参考，具体项目会有所不同。生产过程中会有专人同步进展信息。

## 4. 订购、付款与物流

**获取资料**：全部产品信息、规格书、操作说明与示例代码都可以从官方 GitHub 仓库获取：https://github.com/VIEWESMART/

**下单方式**：通过邮件或留下联系方式沟通，说明订单的详细要求；确认付款信息无误后即可安排发货。

**付款条件**：

- 批量订单：通过 T/T（电汇）支付
- 样品与小订单：可通过 PayPal 或信用卡支付

**运输费用**：根据收货地址与订购数量核算后提供报价。

## 5. 长期供应保证

长期项目最关心的问题是：开发周期拉长之后，原来的显示屏是否还能持续供货。我们的承诺是长期连续供应，不会中途停止供货。

具体做法上，如果某些驱动 IC 面临停产，会尽最大努力找到完全兼容的替代型号；若对应的模具已不存在，则重新开模，并选用性能最接近的 IC 作为替代。因此即使研发周期很长，也不必担心供货中断。

## 6. 常见问题（FAQ）

??? question "Q1：定制显示屏的起订量是多少？"
    标准品 MOQ 为 1 件，可以直接采购。定制项目的 MOQ 通常在 500 至 3000 件之间，具体取决于定制内容与工艺难度。如果项目仍在验证阶段，可以先安排小批量试产；年需求超过 3000 件的项目，也可以拆成多个批次交付。

??? question "Q2：定制打样需要多久？"
    样品生产通常需要 7 至 25 个工作日。周期长短主要取决于定制程度、物料齐套情况与工厂排期，含开模或特殊工艺的项目会偏向上限。该时间仅为参考，下单前建议与对接人确认当期的实际排期。

??? question "Q3：为什么小批量定制的单价更高？"
    因为定制订单需要分摊一次性设置费用，包括开模、治具制作与首件确认等，这些成本与数量无关。当订单量在 500 件以下时，这部分固定成本摊到每件产品上就会明显推高单价。批量越大，固定成本占比越低，单价也越接近标准版本。

??? question "Q4：如何获取产品规格书与示例代码？"
    全部产品信息、数据表、操作说明与示例代码都可以从官方 GitHub 仓库（https://github.com/VIEWESMART/）获取。如需特定型号的完整规格书或定制项目的评估资料，也可以直接联系技术支持获取。

??? question "Q5：显示屏的长期供应如何保证？"
    我们承诺长期连续供应。若关键驱动 IC 停产，会优先寻找完全兼容的替代型号；如果原有模具已不可用，则重新开模并选用最接近的 IC 替代。这样一来，即使产品生命周期很长，也能维持稳定供货。

??? question "Q6：支持哪些付款方式？"
    批量订单通过 T/T（电汇）支付；样品与小订单可通过 PayPal 或信用卡支付。运输费用会根据收货地址与订购数量核算，确认付款信息无误后即安排发货。
