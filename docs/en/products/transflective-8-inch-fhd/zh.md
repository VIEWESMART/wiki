### 1.2 四大核心优势
1. **户外强光原生可视**
    像素分区半透半反结构：一半透射窗、一半反射金属镜。户外强光下关闭背光，依靠环境光反射成像，彻底解决屏幕泛白、看不清问题，无需额外遮光罩。
2. **整机功耗大幅降低**
    对比传统1000nits高亮透射屏，白天户外场景功耗降低80%，设备续航可翻倍；野外测绘、无人机遥控等电池设备收益显著。
3. **工业级宽温稳定**
    经过240小时可靠性老化测试，-20℃低温无拖影、70℃高温无色彩漂移，适配车载、野外勘探、军工便携设备。
4. **高分辨率+全场景触摸**
    1200×1920视网膜级清晰度，地图、航拍视频、CAD图纸细节完整；电容触摸兼容雨天湿手、薄橡胶手套操作。

### 1.3 透反TFT基础工作原理
每个像素微观分为两个独立区域：
- **透射区**：透明窗口，背光LED发光穿透，室内/夜间使用；
- **反射区**：底层高反射金属膜，户外强光下反射环境光成像，背光可完全关闭。

三种工作模式自动适配环境：
- 强光户外：反射模式，背光OFF，极致省电；
- 室内/隧道暗光：透射模式，背光ON；
- 阴天/弱光室内：透反同步叠加，平衡亮度与功耗。

## 2. 快速上手点亮指南（客户首选）
### 2.1 硬件最小系统接线
#### 2.1.1 电源分组要求
1. 模组逻辑供电：3.3V（纹波＜50mV，推荐10uF+0.1uF滤波电容）
2. MIPI信号IO电平：1.8V
3. 背光驱动：LED恒流PWM调光，支持0~100%占空比调节
4. 触摸TP供电：2.8V/3.3V I2C通讯

#### 2.1.2 关键信号定义
- MIPI_DP/DN ×4：4组差分数据通道
- MIPI_CLK_DP/DN：差分时钟
- RST_N：低电平复位（上电保持10ms低电平释放）
- BL_PWM：背光亮度调节引脚
- TP_SDA/TP_SCL：电容触摸I2C总线
- TP_INT：触摸中断引脚（下降沿触发）

!!! warning "上电时序强制规范"
    1. 先给3.3V逻辑电上电；
    2. 拉低RST_N ≥10ms；
    3. 释放复位，等待20ms面板初始化；
    4. 输出MIPI时序信号；
    5. 最后开启背光BL_PWM。
    时序颠倒会直接导致花屏、无显示。

### 2.2 软件初始化流程
#### 2.2.1 透反模式寄存器配置要点
1. 基础MIPI DSI时序配置（1200×1920 60Hz竖屏时序）
2. 透反切换寄存器：
    - `REG_0x05`：0x00=纯反射(背光关闭) / 0x01=混合透反 / 0x02=纯透射
3. Gamma校正：户外模式启用户外Gamma曲线，提升阳光下对比度
4. 触摸I2C地址：0x14，中断上升沿唤醒

#### 2.2.2 最简代码框架（Linux DSI示例片段）
```c
// 1. 硬件复位
gpio_set(RST_N, 0);
msleep(10);
gpio_set(RST_N, 1);
msleep(20);

// 2. MIPI时序初始化
mipi_dsi_set_timing(1200, 1920, 60);
mipi_dsi_write_reg(0x05, 0x00); // 户外纯反射模式，关闭背光

// 3. 背光控制
pwm_set_duty(BL_PWM, 0); // 户外完全关闭背光省电
// pwm_set_duty(BL_PWM, 80); // 室内透射模式80%亮度

// 4. 电容触摸初始化
i2c_write(TP_ADDR, TP_RST, 0x01);
irq_request(TP_INT, touch_isr);
```

## 3. 硬件设计规范（量产避坑）
### 3.1 MIPI差分布线要求
1. 4组数据差分对内等长误差＜5mm；通道间长度误差＜20mm；
2. 差分阻抗控制100Ω±10%，远离电源、电机、射频天线；
3. FPC连接器下方完整GND铺铜屏蔽，降低EMI干扰。

### 3.2 背光与电源设计
- 禁止直接直流硬开背光，必须PWM调光；
- 电源入口增加TVS管ESD防护，户外设备建议增加防雷器件；
- 整机电池供电场景，建议动态检测环境光传感器自动切换透反模式。

### 3.3 结构装配注意事项
- 表面3H硬化盖板，装配避免重压FPC弯折区域；
- 户外整机需做密封遮光结构，防止侧边漏光降低反射对比度。

## 6. 触摸TP专项调试指南
### 6.1 核心特性
- 多点电容触摸，支持最多10点；
- 兼容：薄橡胶手套、湿手、轻微雨水表面；
- 驱动IC内置，FPC一体引出，无需额外外挂TP板。

### 6.2 常见触摸问题
1. 触摸漂移：检查3.3V供电纹波，增加10uF滤波电容；
2. 雨天断触：开启寄存器`TP_WET_EN=1`；
3. 手套无响应：配置`TP_GLOVE_MODE=1`。

## 7. 常见故障FAQ（客户高频问题）
### 7.1 屏幕完全不亮
1. 排查3.3V、1.8V供电是否到位；
2. 确认RST复位时序是否满足10ms低电平；
3. MIPI时钟差分线是否短路、FPC是否插反；
4. 背光PWM是否输出有效占空比。

### 7.2 户外屏幕发白看不清
- 未切换至反射模式，寄存器`REG_0x05`配置为0x00；
- 盖板未做防眩光处理，推荐配套AG防眩光盖板；
- 侧边漏光，整机结构遮光不足。

### 7.3 花屏/横纹/闪屏
1. MIPI差分线不等长、阻抗不匹配；
2. 电源纹波过大，增加LC滤波；
3. 上电时序错误，复位时长不足；
4. 环境低温低于-20℃，增加低温预热初始化。

### 7.4 触摸失灵/断触
- I2C总线上拉电阻缺失（推荐4.7K）；
- TP_INT中断引脚未配置输入上拉；
- 射频天线靠近FPC，电磁干扰屏蔽不足。

### 7.5 功耗偏高无省电效果
- 背光未完全关闭，PWM占空比未拉至0；
- 寄存器未开启纯反射模式，背光持续微亮；
- 整机其他外设未休眠，额外耗电。
